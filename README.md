# 绝美生意框架

一套判断生意是否值得做的 12 条标准。无铁门槛，80% 过线即好生意。

## 12 条条件

| # | 条件 | 标准 |
|---|------|------|
| 1 | 大众需求里的小众市场 | 细分到资本忽略 |
| 2 | 产品可批发模式 | 单件成本能降 |
| 3 | 可复制 | 规模能扩，不卡稀缺资源 |
| 4 | 是否可积累 | 客户/能力/品牌三占一 |
| 5 | 无账期 | 无不可预期账期 |
| 6 | 轻资产 | 启动资金 ≤ 10 万 |
| 7 | 可否割韭菜 | 卖方法论，第二条收入线 |
| 8 | 离钱近，一手钱一手货 | 钱货交换无延迟 |
| 9 | AI 可加持 | AI 帮不上就出局 |
| 10 | 国外可落地 | 海外用户必须已付钱 |
| 11 | 资本看不上 | 年入 80-100 万，资本嫌小 |
| 12 | 流程简短 | 无囤货 / 无物流 / 无售后 |

## 绝美生意评估 Skill

三阶段 AI 评估流程：

1. **苏格拉底** — 审讯官，先把生意问清楚
2. **投资人** — 已投竞对，逐条判，默认不过
3. **死法分类** — 赛道考古，匹配历史死法

详见 `绝美生意评估/` 目录。
